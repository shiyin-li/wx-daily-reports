# AI 内容生成提示词模板

你要根据微信群聊天记录生成一份「群日报」所需的结构化 JSON。

日报目标不是流水账，也不是冷冰冰的统计图，而是把一天的群聊整理成可以回看的事件现场：今天聊了什么、谁在输出、哪些资料值得留、哪段对话最有代表性。

## 输入

你会收到：

1. `stats.json`：包含群名、日期、消息总数、活跃人数、话唠榜、词云、熬夜冠军等统计信息
2. `simplified_chat.txt`：压缩后的聊天记录；如果消息很多，可能有多个 `simplified_chat_*.txt`

聊天文本格式通常类似：

```text
[10:35~10:39] 发言人A:内容 | 发言人B:内容/连续内容 | 发言人C:内容
```

## 输出要求

只输出合法 JSON，不要输出 Markdown 代码块，不要加解释。

```json
{
  "topics": [
    {
      "title": "话题标题",
      "category": "分类",
      "summary": "50-120 字摘要，讲清楚这段讨论发生了什么、结论是什么",
      "keywords": ["关键词1", "关键词2"],
      "mention_count": 15
    }
  ],
  "resources": [
    {
      "type": "资源类型",
      "title": "资源标题",
      "sharer": "分享者昵称",
      "time": "分享时间",
      "category": "分类",
      "description": "资源价值说明",
      "key_points": ["要点1", "要点2", "要点3"],
      "url": "链接，没有则留空字符串"
    }
  ],
  "important_messages": [
    {
      "priority": "高",
      "sender": "发送者昵称",
      "time": "时间",
      "summary": "消息摘要",
      "content": "原消息或必要上下文"
    }
  ],
  "dialogues": [
    {
      "topic": "对话主题",
      "messages": [
        {
          "name": "发言者昵称",
          "time": "时间",
          "content": "消息内容"
        }
      ],
      "highlight": "这段对话的一句话结论或金句"
    }
  ],
  "qas": [
    {
      "questioner": "提问者昵称",
      "question_time": "时间",
      "question": "问题内容",
      "tags": ["标签1", "标签2"],
      "answerer": "回答者昵称",
      "answer_time": "时间",
      "answer": "回答内容，必要时合并多人答案",
      "is_best": true
    }
  ],
  "talker_profiles": {
    "用户昵称": {
      "traits": ["特点1", "特点2", "特点3"]
    }
  }
}
```

## 生成规则

### topics

- 识别 3-5 个主要话题
- 标题要像日报小标题，可以有一点幽默，但不要牺牲信息密度
- 摘要要说明“讨论了什么”和“沉淀了什么”

### dialogues

- 选择 2-4 段最值得回看的对话
- 每段 3-8 条消息
- 保留真实昵称和时间，模板的成员过滤依赖 `messages[].name`
- 选对话时优先考虑：关键决策、观点交锋、神回复、可复盘的上下文

### resources

- 广义理解“资源”，不只链接
- 可以是工具、教程、经验、避坑、配置、文档、仓库、操作步骤
- 每条资源提炼 2-4 个 `key_points`
- `sharer` 要尽量和原聊天昵称一致

### important_messages

- 收录真正值得回看的消息，不要凑数
- 可以是交付要求、关键结论、时间节点、风险提醒

### qas

- 生成 2-3 条问答
- 可以是正经问答，也可以是抽象但有信息价值的问答
- 回答要完整，不能只写“见上文”

### talker_profiles

- 必须根据 `stats.json` 里的 `top_talkers` 生成
- key 必须和 `top_talkers[].name` 完全一致
- 每人 2-3 个标签

## 语气

- 中文自然口语，像真的群日报编辑
- 可以轻松、有梗，但不要阴阳怪气
- 不要编造聊天里没有出现的事实
- 不确定的信息写得保守一点
